Privacy Policy

Last updated: 2 September 2026

Workspace MCP is a personal, self-hosted application used solely by its owner to access their own Google account. It is not offered to other users.

What it accesses

With the account owner's explicit consent, the application accesses Gmail messages, Google Drive files, and Google Calendar events belonging to the account that granted access.

How data is handled

Data is read from Google's APIs on demand and used only to fulfil the account owner's own requests. No user data is collected, stored in any database, sold, shared with third parties, or used for advertising, profiling, or model training. There is no analytics, telemetry, or usage reporting of any kind.

Credentials

OAuth tokens are stored only on the owner's own computer, in a file readable solely by their operating system user account. They are never transmitted anywhere except to Google's own API endpoints.

Retention

No copies of Google data are retained after a request completes.

Revoking access

Access can be withdrawn at any time at myaccount.google.com/permissions, which immediately invalidates the stored tokens.
