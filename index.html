Workspace MCP

A personal Model Context Protocol server for Google Workspace.

Workspace MCP is a self-hosted tool that lets an AI assistant work with the owner's own Google account — searching and sending Gmail, reading and editing Google Drive files, and managing Google Calendar events including Google Meet links.

It runs locally on the owner's own machine using their own Google Cloud OAuth client. It is a single-user personal utility and is not offered as a service to anyone else.
